## 可视化与交互复核

内置浏览器启动因 Windows 沙箱内部错误失败，Edge 连接插件等待 60 秒后超时，因此改用 Playwright 驱动已安装的 Microsoft Edge。工具限制未阻止本机浏览器自动化测试。

使用 `view_image` 实际检查生成概念图和最终浏览器截图；原图尺寸 1487×1058，桌面截图采用同尺寸，手机采用 390×844。布局数据见 `evidence/layout.json`：body 与视口相等，三栏 overflow 均为 auto，无页面脚本错误。

| 比较点         | 概念意图与实际检查                          | 修正或有意差异                                                                         |
