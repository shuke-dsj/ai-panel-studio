## 入包与复现

入选场次包含 1 位主持人、2 位专家、14 条完整现场记录、2 条共识、1 条有历史证据的已关闭分歧和 1 条待外部确认。原文保留了一处历史表述偏差：#9 把 #7 的立场描述成自己撤回“运行时确认当班人”。实际提出该立场的是 #5 的周岚，归档判定以周岚在 #10 的明确撤回及双方 #13、#14 的确认作为交叉证据。

源码中的 [离线归档](../server/examples/knowledge-base-pilot.json)保留阵容、原始时间、发言与引用 ID、当前成果、议题历史和总结。原运行时事件流、模型请求日志和检查点不纳入离线归档。使用全新数据库执行 `npm run db:init` 或启动服务即可查看，过程不需要 API Key。已有同 ID 的本地记录保留原来源和内容。这里的复现指浏览同一份原始记录和证据，模型重新生成没有确定性保证。

已覆盖 1/5 个真实示例主题。还缺小团队微服务、AI 编程工具进入代码评审、免费产品转向订阅、AI 客服人工接管四个主题的真实运行和逐场审阅。五组人工示例保留，并与真实模型档案分别标识。

验收实测：独立空库连续两次执行 `db:init`，均为 5 组人工示例和 1 组真实归档。读取归档后逐条对照角色、发言 ID/原文/回复引用、成果和总结。桌面 1440×900 与手机 390×844 可查看完整更新时间和专家人数，浏览器验收发出的写请求为 0。
