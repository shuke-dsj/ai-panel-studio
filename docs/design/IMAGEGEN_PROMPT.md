Full desktop primary screen at 1440x1000, flat straight-on screenshot, no device frame. Strict useful app layout, no marketing hero, no invented metrics. Right 300px '讨论成果' rail, green '共识' section with 2 short consensus items and supporting message references, amber '分歧' section with 2 competing positions. Footer quiet 'AI 生成内容，请独立判断'. This is a reference screenshot, not production bitmap.
