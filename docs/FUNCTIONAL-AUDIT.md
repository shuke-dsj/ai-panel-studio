## 真实短讨论验收

本轮已执行 model:probe 和一场4位专家、最多6次专家发言的真实短讨论。初始4,000输出Token预算造成截断，自动重试后暂停；保留失败现场并调为8,000后，从同一场的检查点恢复成功，未另开场次。`npm run test:real` 通过本地API执行产品流程，以只读方式重新查询SQLite对照快照、消息ID、摘要、最终状态及完成事件，并检查成果更新发生在结束前。`--resume ID`支持恢复或复核已结束的同一场，不重复创建讨论。

脚本输出 `docs/evidence/real-smoke-latest.json`，不保存 key、服务地址或隐藏推理。随后人工审阅：后发专家是否真正回应前文、分歧是否具体、共识是否有足够支持、总结是否保留反对意见。没有形成某种成果不自动视为失败，不强迫模型编造共识或争议。
