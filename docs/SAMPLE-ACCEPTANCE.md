## 原文与交付成果

发言原文、发言者、时间、顺序和回复 ID 保持原样。交付归档采用审阅后的成果投影和由同一总结函数重生成的总结。微服务把条件未验证的路线归为待确认并补入双方支持的验收动作。代码评审收窄旁路共识及负责人归因。订阅改按 #8–#10 最新表态标注未批准试点。客服更新过期的字段立场并收窄共识。原始运行数据库与未审阅快照留在本地忽略目录。

自动验收逐条检查引用原文、角色一致性、共识至少两位专家、完整来源和重复导入。已存在同 ID 的本机记录不会被种子覆盖。建议验收以全新数据库读取本包。
